------ Networking stuff -----------
NAT GW - (Not cross-AZ) - Deploy one NAT Gateway per AZ. Cannot route between VPCs Not for VPC Peering/VPN use cases. Elastic IP, required at creation

NACL - Default NACLs allow everything, but Custom NACLs deny everything by default until you add rules.
        - NACLs operate at Layer 4 (TCP/UDP), not Layer 7 (HTTP)

Security Groups - You can reference another SG as a source/destination instead of CIDR IPs.
               - EC2 can have multiple SGs (5max)
               - do not block traffic (But implict deny if no match)
               - Default SG denies all inbound. Allows all outbound. Allows other instances in same SG (intra-SG communication)
               - custom SG (you create) default is: denies all inbound. Allows all outbound. 
               
Route Tables - You associate route tables with subnets, not instances or security groups. 
             - 1 Subnet = 1 RT, not 2
             - 1 VPC = 2+ RTs
             
Gateway Endpoints - update route tables, while Interface Endpoints update DNS resolution.       
            
Blackhole Routes = A route whose target is deleted (e.g., deleted NAT GW, VPN, TGW) becomes a blackhole
                - broken connectivity possibly due to a blackhole route.

API GW ERRORS
    4xx means Client errors
        - 400: Bad Request
        - 403: Access Denied, WAF filtered
        - 429: Quota exceeded, Throttle / Too Many Requests 
        - 413 Payload Too Large 
             (10 MB limit, both HTTP and REST).
    5xx means Server errors
        - 502: Bad Gateway Exception
            - Invalid response from the integration
            - eg. Lambda returned malformed JSON
            - API Gateway couldn't connect to the backend (e.g., a Lambda timeout or failure).
            (or a server upstream, has received an invalid response)
        - 503: Service Unavailable Exception
            - Backend or integration temporarily unavailable.
            - The backend service is unavailable. Could be throttled or down.
        - 504: Integration Failure - Endpoint Request Timed-out Exception / Gateway Timeout	Integration 
            - API Gateway requests time out after 29 second maximum
